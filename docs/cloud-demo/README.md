# 当前云环境演示

验证日期：2026-10-14（Asia/Shanghai）。本版本从用户提供的无依赖、无图片源码包导入，使用 SQLite 演示数据，没有连接原 MySQL 数据库。

服务在当前云环境中运行，网页和 API 共用端口 3101。此云环境界面不支持可分享的网页预览地址；本次交付提供运行配置、截图和可下载版本，没有发布公网网站。

## 验证范围

- 前后端类型检查、H5 与后端构建通过。
- 9 项隔离数据库集成测试通过，无跳过项。
- 85 个读取接口返回成功；缺少必填 baseId 的请求按预期返回 400。
- 入场状态、纸箱出入库及不足回滚、配货重复提交与撤销、质检标记与撤销、冷库完成后准确扣减已验证。
- 初始化重复执行保留数据；服务器重启后数据库可继续读取。
- 图标结构校验通过，图标为候选替代资产，未经现场识别测试。

未验证微信小程序、实体摄像头/扫码枪、外部真实物流服务、生产并发和正式财务结算。

## 下载后使用

使用 Node.js 24+，在项目根目录执行 `npm ci`，随后 `npm run demo`。下载包包含构建文件及 SQLite 演示数据库，不包含 node_modules、原本地数据库凭据或认证密钥。首次初始化命令会生成本机独立密钥，已有演示数据会保留。详细开发与重建命令见根目录 README。
